# 나비 날개 AR

카메라에 사람이 잡히면 어깨 뒤로 나비 날개가 펼쳐지는 웹앱입니다.
실제 나비 11종의 도감 데이터로 날개를 그리고, 나만의 날개를 직접 디자인하는 모드도 있습니다.

설치할 것도, 서버도 필요 없습니다. 이 폴더의 파일을 그대로 올리면 끝입니다.

---

## 깃허브에 올리기 (웹 화면만으로)

**1. 저장소 만들기**

[github.com/new](https://github.com/new) → 이름은 `butterfly-wings` 처럼 영문 소문자로.
**Public(공개)** 으로 만들어 주세요 — 무료 계정은 공개 저장소에서만 GitHub Pages가 켜집니다.
("Add a README file" 체크는 하지 마세요. 여기 README가 이미 있습니다.)

**2. 파일 올리기**

만들어진 저장소 화면에서 **uploading an existing file** 을 누르고,
이 폴더 안의 **파일들을** 드래그해 넣습니다. (폴더째가 아니라 안의 내용물)
`tools` 폴더도 함께 올리면 됩니다.

맨 아래 **Commit changes** 를 누릅니다.

> `.nojekyll` 은 점으로 시작하는 숨김 파일이라 드래그에 안 잡힐 수 있습니다.
> 안 올라가도 괜찮습니다. 굳이 넣으시려면 **Add file → Create new file** 에서
> 이름에 `.nojekyll` 만 적고 내용 없이 커밋하세요.

**3. Pages 켜기**

저장소 **Settings** → 왼쪽 메뉴 **Pages** →
Source 를 **Deploy from a branch**, Branch 를 **main** / **/ (root)** 로 두고 **Save**.

1~2분 뒤 같은 화면 위쪽에 주소가 뜹니다:

```
https://<깃허브아이디>.github.io/butterfly-wings/
```

이 주소를 아이들에게 주면 됩니다. GitHub Pages 는 https 라서 카메라 권한이 정상적으로 뜹니다.

## 나중에 고칠 때

저장소에서 그 파일을 누르고 연필(Edit) 아이콘 → 고치고 **Commit changes**.
또는 같은 이름의 파일을 다시 업로드하면 덮어쓰기됩니다. 1~2분 뒤 반영됩니다.

화면이 그대로면 새로고침을 두 번 하세요. 앱이 두 번째 방문부터 빨리 열리도록
파일을 잠깐 저장해 두기 때문입니다(서비스 워커).

## 파일 설명

| 파일 | 하는 일 |
|---|---|
| `index.html` | 앱 전체 — 화면, 카메라, 날개 그리기, 디자인 모드가 모두 이 한 파일에 있습니다 |
| `butterflies.json` | **나비 도감.** 종을 늘리거나 색·모양을 바꾸는 곳 |
| `sw.js` | 두 번째 방문부터 빨리 열리게 하고, 인터넷이 끊겨도 열리게 합니다 |
| `manifest.webmanifest` | 홈 화면에 추가했을 때 쓰는 이름과 아이콘 |
| `icon-*.png` | 홈 화면 아이콘 |
| `tools/gengeo.py` | 날개 윤곽선을 다시 계산해 `butterflies.json` 을 만드는 스크립트 (앱 동작에는 필요 없음) |

인터넷에서 가져오는 것은 자세 인식 모델 하나뿐입니다(약 3 MB). 처음 한 번만 받고 이후엔 저장해 둡니다.

## 나비 종 늘리기

`butterflies.json` 의 `species` 배열에 레코드를 하나 더하면 끝입니다. 앱 코드는 건드리지 않습니다.
파일 맨 위 `howTo` · `fields` · `renderFields` · `ops` 에 좌표계와 쓸 수 있는 무늬가 정리되어 있습니다.

간단히:

- 날개 뿌리가 `(0,0)`, 날개 폭 `1.0` 기준. x는 바깥쪽이 +, y는 아래쪽이 +. 앞날개는 y가 음수.
- `fore` / `hind` / `tail` 은 베지어 윤곽선, `foreEdge` / `hindEdge` 는 날개맥이 뻗는 방향점.
- `scallop` 은 공작나비처럼 가장자리가 우글우글한 종에 씁니다.
- `band.tail` 이 있으면 꼬리와 뒷날개의 테두리가 이음매 없이 이어집니다.
- 무늬 색에 `"$deep"` `"$mid"` `"$bright"` `"$edge"` `"$spots"` 를 쓰면 그 종의 팔레트를 따라갑니다.

## 쓸 때 알아두면 좋은 것

- **카메라 권한** — 사파리에서 거부했다면 주소창 왼쪽 「아A」 → 웹사이트 설정 → 카메라를 «허용».
- **카카오톡·인스타에서 열면** 앱 안의 브라우저라 카메라가 막힙니다. 안내 화면이 뜨면서
  사파리·크롬으로 넘어가는 버튼을 보여 줍니다.
- **여러 명이 잡히면** 「각자」 버튼이 나타나 사람마다 다른 나비를 줍니다.
- **「나만의 나비 디자인」** — 모양을 고르고 색상환에서 색을 칠합니다. 칠하지 않은 곳은
  투명한 날개가 되고, 테두리는 늘 가는 실선으로 보입니다.
